# 剧本 YAML Schema 设计文档

## 概述

本文档定义了 **AI 小说转剧本工具** 所使用的剧本 YAML 格式规范。
该 Schema 用于将小说内容转换为结构化的剧本，以便作者在获得初稿后
能够快速编辑和进一步打磨。

---

## 1. 设计原则

### 1.1 忠实于原著，服务于改编
Schema 保留原小说的核心叙事元素（角色、情节、场景），
同时按照剧本的格式重新组织，降低改编门槛。

### 1.2 层级清晰，逐层细化
按「幕 → 场 → 内容」三级嵌套组织，符合剧本创作的习惯，
从宏观到微观逐层把控。

### 1.3 区分三种内容类型
将小说中的不同叙事成分映射为三种剧本元素：

| 小说成分 | 映射为 | 说明 |
|---------|--------|------|
| 叙述性文字 | 动作描写 | 描述角色行为和事件发展 |
| 对话 | 对白 | 保留原对话并标注角色 |
| 场景转换/气氛 | 舞台指示 | 提示灯光、音效、场景切换 |

### 1.4 可编辑优先
YAML 格式天然易于阅读和编辑，配合工具的在线编辑器，
作者可以快速修改角色台词、调整场景顺序。

---

## 2. 完整 Schema 定义

```yaml
剧本:
  # -----------------------------------------------------------
  # 元数据 — 作品的标识信息
  # -----------------------------------------------------------
  元数据:
    标题: <string>               # 剧本标题，默认取小说名
    原作: <string>                # 原著小说名称
    原作者: <string>              # 原著作者
    改编章节数: <integer>         # 参与改编的小说章节数量
    转换日期: <string>            # 转换日期，格式 YYYY-MM-DD

  # -----------------------------------------------------------
  # 角色表 — 剧中全部角色列表
  # -----------------------------------------------------------
  角色表:
    - 角色名: <string>            # 角色名称（必填）
      年龄: <string>              # 年龄，未知填"未知"
      性别: <string>              # 性别
      性格特征: <string>          # 关键词或短句描述
      角色简介: <string>          # 角色的身份、背景和定位

  # -----------------------------------------------------------
  # 幕 — 剧本的主体结构
  # -----------------------------------------------------------
  幕:
    - 幕号: <integer>             # 第几幕，从 1 开始
      幕标题: <string>            # 幕的标题，如"开端""冲突"
      场:                         # 该幕包含的所有场次
        - 场号: <integer>         # 场号，每幕从 1 开始
          场景: <string>          # 场景名，如"雾都街头"
          时间: <string>          # 时间描述，如"傍晚""深夜"
          人物:                   # 本场出现的角色列表
            - <string>
          内容:                   # 本场的具体内容条目
            - 类型: 对白           # 对话
              角色: <string>      # 说话的角色名
              台词: <string>      # 对话内容
              表情: <string>      # 表情或动作指示（可选）

            - 类型: 动作描写       # 动作/叙事
              内容: <string>      # 动作描述

            - 类型: 舞台指示       # 舞台/场景指示
              内容: <string>      # 灯光、音效、场景切换等说明
```

## 3. 字段详细说明

### 3.1 元数据（Metadata）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 标题 | string | 是 | 剧本名称，用户可自定义 |
| 原作 | string | 是 | 标明改编来源，尊重原著 |
| 原作者 | string | 否 | 原著作者署名 |
| 改编章节数 | integer | 是 | 用户输入的小说章节数量，用于后续扩展 |
| 转换日期 | string | 是 | 记录转换时间，方便版本管理 |

**设计原因**：元数据字段确保剧本可溯源、可标识，
在多剧本管理时能够快速定位作品信息。

### 3.2 角色表（Characters）

角色是剧本的灵魂。独立成表而非散落在各场中，有三个好处：
1. **全局视图**：一眼看到所有角色，便于统筹
2. **避免遗漏**：AI 驱动转换时，系统会扫描全剧确保角色无遗漏
3. **可扩展**：未来可以按角色筛选其所有台词（角色本）

### 3.3 幕（Act）与场（Scene）

采用经典的「幕 → 场」两级结构：

- **幕**：对应小说的一个章节或一个大的情节段落
- **场**：对应一个连续时空内的情节片段，场景切换即换场

**设计原因**：小说通常是线性叙事，而剧本是场景驱动的。
分幕分场可以打破小说的线性结构，让作者从"场景"视角重新审视故事。

### 3.4 三种内容类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 对白 | 角色说的话 | `角色: 张三 台词: 你好！` |
| 动作描写 | 角色行为/事件 | `张三推开门，走进房间` |
| 舞台指示 | 场景/技术说明 | `灯光渐暗，后台传来钟声` |

**为什么区分三种类型？**

- **对白**是剧本的核心，独立字段便于后续统计台词量、按角色筛选
- **动作描写**与**舞台指示**分开，方便导演/舞美各取所需
- 在编辑器里可以用不同颜色高亮三类内容，提升可读性

## 4. 示例：完整剧本 YAML

```yaml
剧本:
  元数据:
    标题: 雾都孤儿·改编
    原作: 雾都孤儿
    原作者: 查尔斯·狄更斯
    改编章节数: 3
    转换日期: 2026-06-05

  角色表:
    - 角色名: 奥利弗·特威斯特
      年龄: 12
      性别: 男
      性格特征: 善良、天真、坚韧
      角色简介: 孤儿院出身的孤儿，渴望爱与归属

    - 角色名: 费金
      年龄: "60"
      性别: 男
      性格特征: 狡猾、精明、善于操纵
      角色简介: 窃贼团伙的头目

  幕:
    - 幕号: 1
      幕标题: 济贫院
      场:
        - 场号: 1
          场景: 济贫院食堂
          时间: 傍晚
          人物:
            - 奥利弗·特威斯特
            - 管事
            - 其他孤儿
          内容:
            - 类型: 动作描写
              内容: 长长的木桌旁，瘦弱的孩子们排着队，每人领到一碗稀粥。

            - 类型: 对白
              角色: 奥利弗·特威斯特
              台词: 对不起，先生，我还要一点。
              表情: 怯懦但坚定

            - 类型: 舞台指示
              内容: 全场震惊。管事的勺子掉在地上，发出清脆的响声。

    - 幕号: 2
      幕标题: 伦敦街头
      场:
        - 场号: 1
          场景: 伦敦街头
          时间: 夜晚
          人物:
            - 奥利弗·特威斯特
            - 机灵鬼
          内容:
            - 类型: 动作描写
              内容: 奥利弗在昏暗的街灯下漫无目的地走着。

            - 类型: 对白
              角色: 机灵鬼
              台词: 嘿，小家伙，你看起来需要个朋友。
              表情: 狡黠地笑着
```

## 5. 后续扩展方向

| 特性 | 说明 |
|------|------|
| 角色本 | 按角色提取所有台词，生成角色专属剧本 |
| 场景统计 | 统计每幕每场的角色出场率、台词量 |
| 多格式导出 | 导出为 PDF、HTML、Markdown 等 |
| 剧本对比 | 对比不同版本的剧本差异 |
| 导出标准剧本格式 | 输出为符合行业标准的剧本格式（如 Fountain） |
