1.

我穿越了。

醒来的时候我躺在一个山洞里，头顶是钟乳石，身下是石床，空气里飘着一股说不上来的草药味。

我的第一反应是摸手机。

没有。

第二反应是摸口袋。

空的。

第三反应：我检查了一下自己能不能用命令行。

这听起来很蠢。但我是一个CS研究生，延毕一年那种。对我来说，能跑终端的环境就是安全的环境。

然后我愣住了。

因为我的意识里真的弹出了一个终端界面。

黑色的背景，白色的光标，在最上方闪烁。

我下意识地输入：

```
git --version
```

输出：

```
git version 2.39.2
```

我差点哭出来。

不是因为我穿越到了一个修仙世界。而是因为在这个满世界都是「灵气」「丹田」「经脉」的地方，我的git居然还能用。

外面传来一声惨叫。

「啊——！」

我跑出山洞。隔壁洞府一个穿灰色长袍的年轻人正捂着胸口打滚，脸上青筋暴起，浑身灵气像开了锅的水一样往外冒。

旁边几个人围着干着急。

「他又走火入魔了！快去找长老！」

「来不及了！他灵气已经乱了！」

我蹲下来看了看。

准确地说，我蹲下来，闭上眼睛，用意识扫了一下他体内的灵气流动。我不知道我为什么会这个，大概是穿越附送的功能。

然后我看到了。

他的灵气在丹田处分成两股，各自沿着不同的路径运转。按理说应该合并成一条，但两股灵气在交汇处互相冲撞，谁也不让谁。

我脑子里弹出一行信息：

```
MERGE CONFLICT
- 功法/基础心法/第三层 > 分支A
- 功法/基础心法/第三层 > 分支B
```

我盯着那行字看了三秒。

然后我蹲下来，拍了拍那个在地上打滚的年轻人。

「兄弟，你功法分支合出冲突了。」

他痛苦地抬头看我：「什么……分支？」

「你现在练的功法和之前练的不是同一套，对吧？你最近是不是换过功法？」

他旁边的人抢答：「他上个月改修了烈阳诀！」

「那就对了。」我站起来，「他原来的功法和烈阳诀在第三层有个接口不一致。一个往左走，一个往右走，到交汇处就撞上了。」

「那怎么办？」有人问。

我想了想。

「要么rebase，要么merge。我建议rebase，把他的基础功法回滚到起点，重新apply烈阳诀的改动。」

所有人都用一种看疯子的眼神看着我。

那个在地上打滚的人又惨叫了一声。

好吧。

我蹲回去，把手搭在他肩膀上，闭上眼睛。我的意识里出现了他的功法路径：两条分支，一个base，冲突标记清晰得像IDE里红色的波浪线。

我手动帮他做了rebase。

把基础功法的提交回滚到冲突前的版本，然后把烈阳诀的改动逐条apply上去。第三条的时候又撞了。我改掉那行冲突的灵气路径，继续。

三分钟后，他体内的灵气稳定了。

他睁开眼睛，满头大汗地看着我：「你……你对我做了什么？」

「rebase了一下。」

「……什么？」

「你不需要知道。」

我站起来，拍了拍膝盖上的灰，走回我的山洞。

身后传来他的声音：「师兄！你叫什么名字？」

我头也没回。

「叫我git管理员。」

2.

第二天一早，有人敲我的洞府门。

我打开门，看到一个穿青色长裙的女人站在外面。她腰间挂着一枚玉牌，上面刻着宗门的标志，看起来是个有身份的人。

「你是林慎？」

「是我。」

「我是苏棠，执法堂的首席弟子。听说你昨天用奇怪的方法治好了王师弟的走火入魔。」

我点点头：「然后呢？」

「长老想见你。」

「好。」

她没动，上下打量了我一番。

「你真的是从凡间来的？」她问。

「准确地说，是从另一个世界。」

「什么世界？」

我想了想：「一个满世界都是『前人留下的屎山代码』的世界。」

她没听懂。但她没继续问。

去长老殿的路上，她给我介绍了宗门的基本情况。我所在的门派叫「玄天宗」，方圆三百里最大的修仙门派，有弟子七八百人，金丹以上的长老二十多位。听起来挺厉害。

但我注意到一个细节。

「你们修炼用的功法，是用玉简存的？」

「对。」

「我能看看你们的基础功法吗？」

苏棠犹豫了一下，从怀里掏出一枚玉简递给我：「这是基础心法，入门弟子都练这个。」

我把玉简贴在额头上。

一瞬间，大量的信息涌入我的意识。那是功法的运行路径、灵气流转的方向、每个穴位的功能定义。

就像读一份源代码。

我读了不到十秒钟，瞳孔地震了。

这玩意儿——

第一，变量命名全是单字母。丹田是d，经脉是j，穴位叫x。没有任何注释。没有任何说明。整个功法洋洋洒洒三千多字，看起来就像一个程序员写了一整篇代码但所有变量都叫a、b、c、d。

第二，我数了数。光前两层就有13处冗余循环。同样的灵气路径重复走了好几遍，完全可以合并优化。

第三，也是最炸裂的：有两处无限递归的风险。某两个穴位之间形成了一个闭环，如果灵气量超过某个阈值，会在那两个穴位之间无限循环，直到丹田被抽干。

这就是他们说的「走火入魔」。

不是玄学。

是bug。

我把玉简从额头上拿下来。

苏棠看着我：「你怎么了？脸色不太好看。」

我忍住没有爆粗口。

「你们这个功法，」我说，「时间复杂度是O(n³)吧。」

「……什么复杂度？」

「没什么。是我想多了。」

不是我想多了。是这个世界的代码质量太差了。

我跟着苏棠继续走，但脑子里已经在疯狂运转。那些功法的路径在我意识里像代码一样流动，每一行都有优化的空间。

我才刚来一天。

但手已经开始痒了。

到了长老殿门口，苏棠停下来。

「对了，」她说，「你昨天说的那个……rebase，到底是什么？」

我看着她，笑了。

「你学过版本管理吗？」

「什么管理？」

「没事。回头我教你。」

我走进长老殿的时候，脑子里只有一个念头：我要给这个世界的功法加上版本管理。

不然我受不了。

3.

长老比我预想的好说话。

玄诚真人是个头发花白但精神矍铄的老头，问了我几个关于来历的问题，又考了我一些修炼常识，我基本答不上来，但他似乎并不在意。

「听说你昨天用奇怪的方法治好了走火入魔的弟子。」

「不是奇怪的方法，是rebase。」

「……ra-bis？」

「算了，当我没说。」

他没有为难我，让我挂名在外门，先熟悉宗门的修炼体系。临走前他看了我一眼：「你有什么需要的，可以跟苏棠说。」

我想了想：「能给我一些空白的玉简吗？」

「要多少？」

「越多越好。」

回到洞府，我把领到的十枚空白玉简一字排开。

然后我开始写。

不是写功法。是写工具链。

这个世界的人用玉简存功法，但玉简的功能远不止于此。我发现只要用自己的意识在玉简上刻录信息，别人就能用同样的方式读取。这不就是文件系统吗？

我从基础心法开始。

把那团O(n³)的屎山代码贴到额头上，一字一句地读，然后在意识里重构。

第一步，重命名变量。丹田→dantian，经脉→meridian，穴位→acupoint。虽然长了点，但至少能看懂。

第二步，提取公共路径。那13处冗余循环里，有7处是同一个灵气路径在重复。我把它提取成一个子程序。不对，在这个世界应该叫「小周天循环」。

第三步，标记那两处无限递归。我在对应穴位上加了个注释：// TODO: 这里可能会死锁，灵气量超过阈值时请勿使用此路径。

第四步——

我拿起一枚空白玉简，把重构后的功法刻录进去。

然后我在意识里敲下：

```
git init
```

系统没有任何反应。我的意识里安静了三秒钟。

然后——

```
已初始化空的 Git 仓库于 /丹田/功法/基础心法/
```

我笑了。

```
git add .
git commit -m "feat: 重构基础心法，修复13处冗余循环，标记2处潜在死锁"
```

灵气涌入那枚玉简。重构后的功法在里面安静地运行着，像一个优雅的程序第一次编译通过。

我把它贴在额头上试运行了一下。

灵气从丹田出发，沿着新的路径流转。没有冗余，没有冲突，每一丝灵气都在做有用功。顺畅得像一份没有warning的代码。

但也就在这时候，我觉得不太对劲。

灵气运行到某个穴位的时候，卡了一下。

不是死锁。是一种……微妙的不适应。像齿轮咬合时有一点点偏离。

我把意识沉进去，仔细查了一遍。不是我的问题。是原始功法就有的。

我输入：

```
git log
```

只有一个commit，我自己的。

不对。我应该看看原始版本。

我从旁边拿过那枚原始的功法玉简（苏棠给我参考的），把它的内容和我的版本做了对比。

在卡顿的那个穴位上，原始版本有一段很奇怪的灵气走向。它没有遵循前后文的逻辑，像是有人硬塞进去的。

我盯着那段走向看了很久。

然后我把原始功法做了git初始化，把最原始的版本提交进去。

```
git blame 基础心法/第三层/穴位十七
```

输出：

```
^a3f2c1d (赵无痕 342年前) 穴位十七：增加灵气缓冲
```

342年前。

一个叫赵无痕的人，在342年前改了这个功法。改完之后，这个穴位就变得不正常了。而之后的三百多年里，没人发现。

是因为这个bug太隐蔽了。

或者说，是因为这个世界的人写代码不看diff。

我坐在洞府里，盯着那个342年前的commit hash，沉默了很久。

然后我打开一个空白玉简，开始写注释。

门外传来苏棠的声音：「林慎？你在吗？」

「在。」

她推门进来，看到我面前堆了一桌子的玉简。

「你在干什么？」

「在给你们的祖传屎山写README。」

「……什么山？」

我抬起头。

「你们这个世界没有版本管理，没有单元测试，没有代码review。一套功法传了几百年，没人知道谁改过、为什么改、改之前是什么样的。」

我拿起那枚重构好的玉简：「但以后会有的。」

苏棠看着我，像是看着一个精神病。

但她没有走。

4.

苏棠的瓶颈来得比我预想的快。

三天后的下午，她敲开了我的洞府门。脸色不太好，嘴唇有点发白，额头上有一层薄汗。

「你怎么了？」

「修炼出了点岔子。」她说，「灵气运转到丹田和膻中之间的时候，总是卡住。像……有什么东西堵在那里。」

「多久了？」

「两个月了。我以为是自己修为不够，但最近越来越严重。」

我让她坐下，把手搭在她的手腕上。意识沉进去，沿着她的经脉走了一圈。

丹田没问题。膻中没问题。但从丹田到膻中的灵气路径上，有两股灵气在抢夺同一条经脉的控制权。

一股往上走，一股往下走。在中间撞上了。

谁也不让谁。

典型的死锁。

我睁开眼睛。

「你是不是同时修了两门功法？」

她愣了一下：「你怎么知道？」

「你体内有两股不同属性的灵气。一股偏阳，一股偏阴。它们在争夺同一条经脉的资源。」

「主修是玄天诀，」她说，「但我三个月前加修了一门凝冰诀，师父说阴阳调和有助于突破金丹期。」

「那问题就在这儿了。」

我拿起一枚空白玉简，在意识里画了一张经脉图。从丹田到膻中的这一段。两条路径在这里交汇，但没有任何资源协调的机制。

就像两个线程同时访问同一个共享变量，但没有加锁。

「你这个问题，学术上叫『竞争条件』。两条灵气流同时请求同一条经脉，没有协调机制，撞上了就死锁。」

「……你说什么？」

「简单说，就是你们这个功法体系里没有『信号量』。」

她显然没听懂。我也不指望她听懂。

我贴在额头上开始给她写一个补丁，不是改功法，而是在她的灵气路径上加一个协调层。

当两股灵气同时请求同一条经脉时，由这个协调层决定谁先过。先放一股，等它通过了，再放另一股。轮流通行，互不干扰。

这个叫法在编程里叫「信号量」（Semaphore）。

但在修仙世界里，可以叫它「通脉诀」。

我把补丁玉简递给她。

「把这个加在你的主修功法上。下次运气的时候，先运行这个协调层。」

她接过去，将信将疑地贴在了额头上。

读完之后，她的表情变了。

「这个……真的有用？」

「试试看。」

她闭上眼睛。我看着她体内的灵气开始运转。一开始很慢，到了那个冲突点的时候，她的呼吸顿了一下。我搭在膝上的手也收紧了。

然后协调层生效了。

阳灵气先通行。三息之后，阴灵气跟上。两条路径交替前进，丝滑得像快排算法的最优情况。

她睁开眼睛，瞳孔里有一层光。

「不卡了。」

「当然不卡了。」

「灵气比以前还顺畅……」

「那当然。以前你百分之三十的灵气都在抢资源，现在是实打实全用上了。」

她看着我，那个眼神和之前不一样了。

不是看一个怪人的眼神。是看一个有用的人的眼神。

「你到底是什么人？」她问。

我往后一靠，把脚翘到桌子上。

「延毕一年的研究生。论文被毙了三次。」

「……」

「但debug我是专业的。」

5.

消息传得比我预想的快。

又过了两天，长老殿来人了。不是传唤，是玄诚真人亲自来了我的洞府。

一个元婴期的长老，站在我那个堆满玉简的小山洞里，弯着腰看我的「工作台」。

「这些都是你写的？」

他拿起一枚玉简，贴在额头上。读了几秒钟，放下了。

「这些符号……是什么？」

他说的是变量名。我重构功法的时候把所有单字母变量都改成了有意义的命名。

「我叫它『可读性优化』。」

「……什么优化？」

「你们这个世界的功法有个问题：所有变量都是单字母。d是丹田，j是经脉，x是穴位。写的人自己知道，但看的人全靠猜。这就像一本没有目录的书。」

玄诚真人沉默了。

然后他从袖子里拿出一枚泛黄的玉简。

「这是我师祖传下来的剑诀残篇。宗门三百年来没人练成。你看看。」

我接过来，贴在额头上。

一瞬间，汹涌的信息涌入意识。这是一套剑诀。或者说，是一套本该是剑诀的东西。它给我的第一感觉就是一个编译不过的项目。

我一行一行地读。

读到大半的时候，我找到了第一个问题。

有一段灵气调用，调用的是剑诀外部的一个接口，看起来应该是汇聚天地灵气的一个函数。但这个调用前面没有任何声明。

就像在代码里用了一个函数，但没有#include对应的头文件。

缺少依赖声明。

我在意识里找到了那个接口的定义，它被写在另一套完全不同的功法里。只要在剑诀开头声明这个依赖关系，就能链接上。

我补上了。

然后继续往下读。

第二个问题更离谱。

在剑诀最后一式的关键节点上，有一条多余的灵气转向指令。在编程里，这个东西叫「死代码」。永远不会被执行到，但因为写在关键路径上，影响了整个控制流。

我把它删了。

然后我退出意识，把玉简还给玄诚真人。

「好了。」

他接过去，愣了一下：「好了？」

「修了两个bug。一个缺少依赖声明，一个多余的分号。」

「……分号？」

「就是多余的灵气转向。你们这个世界没有linter，所以没人发现。」

玄诚真人半信半疑地把玉简贴到额头上。

他闭上眼睛，运气。

第一式。

第二式。

到第三式的时候，剑诀的灵气路径开始走一个复杂的回环。那是之前所有玄天宗弟子都卡住的地方。

但这次没有卡。

灵气顺畅地走完了全程。

玄诚真人睁开眼睛，眼中有一种我从未在他脸上见过的表情。

那是一个老程序员看到自己编译了三个月的项目终于通过了的感觉。

「这套剑诀……」

「能用了。」

「不只是能用了。」他看着我，「它的威力比以前至少提升了三成。」

那是因为我顺手优化了一下最后一式的灵气路径，把时间复杂度从O(n²)降到了O(n)。但我觉得这个没必要解释了。

「你做的这些——」他晃了晃手中的玉简，「到底是什么？」

我想了想。

「debug。」

「……」

「你们这个世界管它叫『悟道』。但在我的世界，它叫『调试』。」

6.

一切平静了三天。

第四天，出事了。

先是一个内门弟子在早课上走火入魔。然后是第二个。第三个。半天之内，十七个弟子出现了同样的症状。灵气逆转，经脉胀痛，严重的直接晕厥。

苏棠冲到我的洞府时，我正在写一个自动化测试框架。不对，在这个世界应该叫「自检周天」。

「出事了。」

「我知道。外面已经抬过去五个人了。」

「不止五个。十七个了。」

我放下玉简。

「什么症状？」

「都一样。灵气在运行到第三层某个穴位的时候突然逆转，然后整个人失去控制。」

十七个人，同一种症状。

这不对。

如果是功法的原生bug，早就应该有人出了问题：这些弟子练这套功法最短的也有几个月了。不可能在同一天同时触发同一个bug。

我站起来：「带我去看一个人。」

功法大殿里躺了七八个弟子，全是面色发白，灵气紊乱。我蹲在其中一个旁边，手搭在他的手腕上，意识沉进去。

沿着灵气路径一路走。

到第三层的时候，我找到了问题。

有一个穴位。就是前几天我用git blame发现赵无痕342年前改过的那个穴位，灵气路径被改了。和原始版本不一样。

我没有改过这个位置。

但有人改了。

我站起来，从怀里掏出自己的功法玉简。我在第一天重构之后提交的版本。贴在额头上读了一遍。

我commit的版本里，这个穴位是正常的。

但现在宗门弟子在练的版本，不是我的版本。

我跑到藏经阁，找到那枚公开发放的基础功法玉简。贴在额头上。

果然。

有人在我重构之后，又修改了功法玉简。改的就是那个342年前被赵无痕动过的穴位。这次改得更狠，直接把灵气路径反转了。练到这个地方，灵气会逆向运转，轻则重伤，重则走火入魔。

这不是bug。

这是被人故意投毒。

我闭上眼睛。我的意识里弹出了我commit的第一个版本。我管它叫v1.0。然后我调出当前的版本，被人改过的版本。

我把两个版本在意识里并列。

然后我输入：

```
git diff v1.0 HEAD
```

输出：

```
--- a/基础心法/第三层/穴位十七
+++ b/基础心法/第三层/穴位十七
@@ -42,5 +42,5 @@
-灵气沿任脉上行，经膻中入丹田，循环往复
+灵气沿任脉上行，经膻中逆转，逆行入丹田
```

红色的删除线。绿色的新增线。

改动的行，清晰地浮现在我意识里。

改这个功法的人，手法很隐蔽。他只改了一行，但这一行足以让所有修炼者在某个特定时刻灵气逆转。

如果不是我有git，我可能永远发现不了这是一次定向攻击。只会以为是功法的又一个bug。

我睁开眼睛。

苏棠在旁边焦急地看着我：「怎么样？」

「功法被人篡改了。」

她的脸色变了：「什么？」

「有人在我的版本上又改了一版，改完直接放回了藏经阁。弟子们拿到的是被人动手脚之后的版本。」

「谁干的？」

我盯着意识里那条diff记录的元数据。

```
Author: 匿名
Date: 昨晚子时
```

没有名字。git没有记录到身份信息。这个世界没有SSH key的概念，谁拿到玉简都能直接修改。

但有一个信息是抹不掉的。

修改时使用的洞府灵气坐标，这个世界的「IP地址」。

我把那个坐标投影到空中，一个由灵光组成的三维坐标。

苏棠看了一眼，瞳孔收缩了。

「这是……内门长老区的坐标。」

我把diff结果也投影到空中。红色的删除线和绿色的新增线，在所有人面前清晰刺眼。

「看到没？」

我指着那行改动。

「有人在你们的功法里种了一个后门。要不是有git，你们要等所有人都走火入魔了才发现。」

7.

当晚，长老殿开了紧急会议。

玄诚真人坐在主位，旁边是几位内门长老。我站在大殿中央，苏棠站在我旁边。

气氛很严肃。但对我来说，这个问题很简单。我直接上证据。

我把被篡改的功法版本和我commit的原版之间的diff投影到大殿上空。

全息投影一样的红色和绿色线条，在所有人面前展开。

「这是子时到丑时之间的改动记录。」我说，「有人拿着玉简，在藏经阁里直接修改了功法。他只改了一行。这一行让所有修炼者在第三层穴位处灵气逆转。」

一个长老开口：「你怎么证明不是你改的？」

我料到会有人这么问。

「因为我有版本历史。」

我调出git log，投影在空中。

```
commit a1b2c3d (HEAD -> master)
Author: 林慎
Date: 三天前

    feat: 重构基础心法，修复13处冗余循环，标记2处潜在死锁

commit e4f5g6h
Author: 匿名
Date: 昨晚子时

    （无提交信息——直接修改）
```

「看清楚了？我的commit在三天前。那个恶意修改在昨晚。时间线是完整的，改不了。」

那个长老闭嘴了。

玄诚真人开口了：「能查出是谁做的吗？」

「我查到了修改时使用的洞府灵气坐标。苏棠说那是内门长老区的。」

所有人的目光转向了坐在角落的一个长老。

那个人面色如常，但他的手在袖子里握紧了。

我没有直接指认他。不需要。我把完整的diff记录、时间戳、坐标，全部刻录到一枚玉简里，交给了玄诚真人。

「该查的人去查。我的职责到这儿为止。」

玄诚真人接过玉简，看了我一眼。

「你的这个……git，」他说，「能部署到整个宗门吗？」

我愣了一下。

「你要把所有功法都纳入版本管理？」

「不止功法。」他说，「弟子修炼记录、丹药配方、阵法图纸，所有需要传承的，都用你的git。」

我沉默了三秒钟。

不是因为我在犹豫。而是因为我在算——八百个弟子的仓库权限设计，分支管理策略，CI/CD管道——

不对，这个世界没有CI/CD。

但可以有。

「可以。」我说，「但有一个条件。」

「说。」

「给我几个弟子当助教。我一个人管不了八百个人的代码提交。」

玄诚真人点了点头。

「准了。」

8.

三个月后。

玄天宗变了一个样子。

不过变得不多。山还是那座山，大殿还是那座大殿，弟子们还是每天早起练功。但多了一些以前没有的东西。

藏经阁旁边多了一间屋子，门口挂着一块匾，写着「功法工程部」。

我取的。

苏棠说这名字太难听了。我说你不懂，这叫企业文化。

每周一和周四，我在功法工程部开课。听课的人从外门弟子到内门长老都有。我给他们讲的东西和修炼没关系。讲的是版本管理、分支策略、代码review的重要性。

当然，用的是修仙世界的语言。

「分支策略」变成了「分脉修炼法」——主修一门功法时开一个主分支，想试新功法就开feature分支，试完了没问题再merge回主分支。「代码review」变成了「双人印证」。任何功法修改必须有另一个人验证过才能提交。

「单元测试」变成了「自检周天」。每次修改功法后自动运行一套完整的灵气路径检测。

听起来玄乎，其实就是工程化的那套东西。

三个月里，成果是实打实的。

弟子的走火入魔率下降了八成。不是因为功法变强了。bug还是那些bug，但能在造成伤害之前被发现和修复。

师姐苏棠突破到了元婴期。她说那个「通脉诀」帮她省了至少五年的苦修。我觉得夸张了，顶多省三年。

玄诚真人偶尔会来我的工程部坐坐，翻翻那些写满注释的玉简，然后摇着头走。有一次我听到他在门外自言自语：「写了三百年都没人发现的问题……他三天就找到了。」

我坐在后山的石头上，打开一枚玉简。

这三个月的心血都在里面：我构建了整个玄天宗的版本管理系统。功法仓库、丹药配方库、阵法图纸库，甚至还包括一份《宗门代码规范》，规定了变量命名的标准格式。

我输入：

```
git log --oneline
```

一长串commit记录滚了出来：

```
a1b2c3d feat: 重构基础心法
e4f5g6h fix: 修复第三层穴位死锁
h7i8j9k docs: 给烈阳诀加README
l0m1n2o feat: 部署自动自检周天
p3q4r5s fix: 炼丹炉温度控制算法优化
```

从第一行到最近一行。是我在这个世界留下的所有足迹。

身后传来脚步声。

一个十五六岁的小弟子站在门口，手里捧着一枚玉简，表情紧张。

「林师兄！」

「嗯？」

「我、我修的那个功法好像有bug……灵气走到第二层的时候会卡住，我查了好几天都找不到原因……」

我把玉简接过来，贴在额头上。

读了两秒钟。

然后我笑了。

这代码是我三个月前写的。

那时候我刚学这个世界的功法语法，写出来的东西跟现在看到的弟子作业一个水平。

「来，坐。」我拍了拍旁边的石头，「我教你git bisect。」

「……什么？」

「二分查找bug。很简单的。」

阳光照在后山的石头上。

远处有人在练剑。近处有人在debug。

这个世界和三个月前不太一样了。

好在我这个人——最不怕的就是debug。
